# v0.1.0

## 中文更新内容

- 发布 Windows 用户权限下的默认文件关联工具。
- 支持 PDF、协议和已安装浏览器关联模式。
- 增加版本受限的 Framework64 MSBuild PDF 研究模式和只读诊断。
- 增加中英文 README、版本清单和 tag 触发的 Windows 构建打包流程。
- 记录五类宿主研究路径及其 Windows 11 26H2 版本限制。

## English changes

- Initial release of the Windows per-user file association tool.
- Add PDF, protocol, and installed-browser association modes.
- Add the version-gated Framework64 MSBuild PDF research mode and read-only diagnostics.
- Add bilingual README files, release manifests, and tag-triggered Windows packaging.
- Document five host research paths and their Windows 11 26H2 limitations.
